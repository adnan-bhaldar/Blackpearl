### Run Locally

To run **Booken** locally, run this command on your git bash:

Linux and macOS:

```bash
sudo git clone https://github.com/adnan-bhaldar/blackpearl.git
```

Windows:

```bash
git clone https://github.com/adnan-bhaldar/blackpearl.git
```
